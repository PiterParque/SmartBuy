🛒 SmartBuy

O SmartBuy é uma plataforma inteligente de comparação de preços desenvolvida para ajudar usuários a encontrarem as melhores ofertas em diferentes marketplaces de forma rápida e eficiente. O sistema centraliza informações de produtos, monitora variações de preços e permite que os usuários acompanhem oportunidades de compra em tempo real.

A aplicação foi desenvolvida utilizando Python, Django, PostgreSQL, Tailwind CSS e está hospedada na plataforma Vercel, combinando desempenho, escalabilidade e uma interface moderna. O projeto também implementa rotinas automatizadas para coleta e atualização de preços, mantendo o histórico de variações para análise de tendências e identificação de promoções.

🚀 Principais Funcionalidades
🔍 Busca e comparação de produtos em múltiplas fontes.
📊 Histórico de preços para acompanhamento de variações.
📉 Detecção automática de quedas de preço.
📧 Sistema de alertas de preço por e-mail.
🖼️ Exibição organizada de imagens, descrições e informações dos produtos.
📱 Interface responsiva para desktop e dispositivos móveis.
⚡ Atualização automatizada de dados através de processos de scraping.
🔐 Estrutura preparada para autenticação e personalização de alertas.

🎯 Objetivo

O SmartBuy foi criado para demonstrar habilidades em desenvolvimento full stack com Python, integração de dados externos, automação de processos e construção de aplicações web escaláveis. O projeto simula uma solução real de monitoramento de preços, oferecendo aos usuários uma maneira prática de economizar em suas compras online.
